# 04 · mdtoc

Generate Markdown tables of contents and validate every link in a repo.

## Run
```bash
python -m mdtoc --help
```

## Test
```bash
pytest projects/04-mdtoc -q
```

See the module docstrings for the design notes; every public function has a test.
